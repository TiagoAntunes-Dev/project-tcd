# Project TCD

Projeto desenvolvido exclusivamente para estudar e compreender o funcionamento do arquivo `.gitignore` no Git.

O objetivo é demonstrar como determinados arquivos podem ser ignorados pelo Git e, consequentemente, não serem enviados para um repositório remoto como o GitHub.

---

## 📚 Objetivo

Este projeto tem como foco o estudo do **`.gitignore`**, um arquivo utilizado pelo Git para definir quais arquivos e diretórios devem ser ignorados durante o controle de versão.

O principal exemplo utilizado neste projeto é o arquivo `.env`, que normalmente contém variáveis de ambiente e informações que não devem ser expostas publicamente.

---

## 🧠 O que é o `.gitignore`?

O `.gitignore` é um arquivo de configuração utilizado pelo Git para informar quais arquivos e diretórios devem ser ignorados.
